# 사내 Nuxt3 보일러플레이트 제작

## 프로젝트 개요
Nuxt3 출시 이전, 필요성을 느껴 혼자 제작한 Nuxt2 보일러플레이트로 팀 내 다양한 신규 프로젝트가 진행되었고, Nuxt3 출시 이후 버전에 맞는 보일러플레이트 제작 필요성이 대두되어 여러 측면에서 좀 더 보완한 보일러플레이트를 다른 프론트 개발자들과 함께 제작한 프로젝트

## 프로젝트 정보
- 사내 보일러플레이트

## 기술 스택
- UI: HTML, SCSS
- FRONT: Nuxt3

## 주요 구현 기능
- 사내 레이아웃 가이드, SCSS 가이드 기본 설정 및 제공
- 필수 디렉터리 구조 제공
- 공통 `.env` 설정
- `ESLint`, `Prettier` 설정
- 자동 배포를 위한 `Docker` 설정

## 성과
- 팀 내뿐만 아니라 타 팀에서도 해당 보일러플레이트를 활용할 만큼 전사적으로 사용됨
- 보일러플레이트를 적극 사용함으로써 초기 Git 세팅 리소스를 확연히 줄이고, 코드의 통일성 확보
- 프로젝트마다 분산되어 있던 ESLint와 Prettier 설정을 협의를 통해 공통화하여 코드 스타일을 통일하고, 이후 유지보수에 기여
- 추후 관리 체계 및 담당을 만들어 유지보수가 진행되었으며, 담당자에게 여러 이슈를 제보하고 제안하여 유지보수에 기여
  - 보일러플레이트를 사용하던 중 Nuxt3 버전이 보안 검수에 걸린 경우가 있어 업데이트 진행을 제안
  - ESLint의 불편한 점을 지속적으로 전달하고 개선 방안을 제안하여 수정되도록 함
  - 사내에서 제작한 특정 모듈 사용 시 충돌이 있는 것을 발견하고 개선 제안
