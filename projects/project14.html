브라우저 확장 프로그램 템플릿 및 기능 모듈 제작

프로젝트 개요

AI 비서 브라우저 확장 프로그램을 개발하며 설계 단계부터 기능을 모듈 단위로 나누어 두었고, 이를 바탕으로 다음 확장 프로그램 개발에 바로 쓸 수 있는 Vue·React 베이스 템플릿과, 필요한 모듈만 골라 템플릿에 설치하는 기능 모듈 저장소를 따로 분리하여 제작한 프로젝트

프로젝트 정보

  • 사내 템플릿 및 모듈 저장소 (프로젝트 결과물로 코드 비공개)

기술 스택

  • FRONT: WXT, Vue3, React, TypeScript
    • Vue, React 두 템플릿 모두 WXT 기반으로 구성

주요 구현 기능

  • WXT 기반 확장 프로그램 베이스를 Vue, React 두 가지 템플릿으로 제공
    • 필수 디렉터리 구조 제공
    • manifest 및 빌드 설정
    • 공통 .env 설정
    • ESLint, Prettier 설정
  • 버튼, 로딩, 토스트, 인풋 등 자주 쓰이는 베이스 컴포넌트 제공
  • 명령어 및 스크립트를 통한 커밋, 푸시, 릴리즈용 압축 파일 생성 자동화
  • 확장 프로그램에서 사용한 기능들을 별도 Git 저장소의 모듈로 분리
  • 스크립트를 실행해 필요한 모듈만 골라 베이스 템플릿에 설치할 수 있도록 구성
    • 모듈 저장소를 의존성으로 끌어오지 않고 모듈 코드 자체를 설치하여, 프로젝트의 공통 디렉터리 하위에 합쳐지도록 처리

성과

  • 설계·구현 단계부터 기능을 모듈 단위로 나누어 개발했기 때문에, 프로젝트 결과물에서 템플릿과 모듈을 수월하게 분리
  • 같은 확장 프로그램 베이스를 Vue와 React 두 가지 프레임워크로 구성하여, 이후 프로젝트에서 팀이 선택할 수 있도록 함
  • 커밋, 푸시, 릴리즈용 압축 파일 생성을 자동화하여 반복되는 릴리즈 준비 작업을 줄임
  • 다음 확장 프로그램 프로젝트에서 초기 세팅과 공통 기능 개발 리소스를 줄일 수 있는 기반 마련
  • Useragent 모듈과 팝업 레이어 모듈에서 private 저장소를 npm으로 설치할 때 겪은 보안·자동 배포 문제를 반영하여, 모듈 코드를 프로젝트에 직접 설치하는 방식으로 설계
