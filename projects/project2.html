kakao IR 미팅 예약 시스템

프로젝트 개요

사용자 페이지를 통해 카카오 ir 미팅을 날짜, 시간별로 신청하고, admin 페이지에서 해당 예약을 관리 할 수 있는 미팅 예약 시스템

프로젝트 정보

  • ir 미팅 예약 시스템
  • admin 사내 시스템

기술 스택

  • UI: html, scss
  • FRONT: Nuxt2

주요 구현 기능

  • Full Calendar라이브러리를 활용한 날짜별 예약 현황 구현
    • Full Calendar라이브러리 내 css 커스텀
    • 날짜별 클릭 이벤트, 드래그 이벤트 등 활용하여 기능 제작
  • 카카오 로그인 연동
    • 페이지 자체 신규 가입 기능 구현
    • 카카오 계정 로그인 연동(소셜로그인) 구현 (Kakao Developers 제공)
  • 다국어 지원
    • 국문, 영문만 지원할 예정으로 i18n 라이브러리 대신 내부에서 컨트롤 할 수 있도록 자체 구현

문제 및 해결

  • 백엔드 개발자와의 협업 문제
    • 문제: 프론트는 제주에서, 백엔드는 판교에서 개발하는 형태였는데, 계속된 요청에도 불구하고 백엔드 개발자가 인프라, api 등을 적절히 제공하지 않고 소통이 불가한 문제가 발생하였다.
    • 해결: 백엔드 개발자에게 지속적으로 소통을 시도 및 요구하였으며, 이 또한 불가능한 상황이 되자 PM을 통해 프로젝트 진행 상황을 알리고, 프론트 쪽에서 대기 중인 상황을 계속 인지시켰다. 결과적으로 백엔드 개발자가 교체되었으며, 프론트 개발 리소스가 촉박하게 되었으나 일정에 맞추어 프로젝트를 완수하였다.

성과

  • 다국어지원에 대해 여러 제공 방안을 검토해보고, 단순 라이브러리를 활용하기 보다는 자체 개발을 통해 더 나은 개발 방식을 적용하였다.
  • 프론트 메인 개발자로서, 프로젝트를 기한 안에 적절히 완수하기 위해 다양한 커뮤니케이션 및 조율을 진행하였으며, 개인적인 성장 기회가 되었다.
