1. ifkakao2020

프로젝트 개요

카카오에서 제공하는 개발자를 위한 컨퍼런스 페이지로, 다양한 세션을 통해 개발 및 테크에 대한 정보를 소개하고 제공하는 페이지

프로젝트 정보

  • ifkakao
  • 2020년도에 제공한 메인, join, mypage 등 주요 페이지 종료

기술 스택

  • UI: html, scss
  • FRONT: Nuxt2

주요 구현 기능

  • 서버타임을 활용한 카운트다운 구현
    • 카운트다운에 맞춰 세션을 공개하는 형태로, 클라이언트에서 날짜 및 시간을 쉽게 변경 가능하기 때문에 서버타임을 활용하여 카운트다운을 구현하였다.
  • 카카오 로그인 연동을 통한 가입 및 마이페이지 구현
    • 카카오에서 제공하는 로그인 모듈을 페이지와 연동하여 관심 분야나 북마크 등을 개인화 할 수 있도록 구성하였다.
  • 카카오톡 웹뷰 내 페이지 구현
    • 카카오톡 인앱 웹뷰 지원을 위한 톡클라이언트와의 협업하였다.

문제 및 해결

  • CSR 방식 구현으로 인한 검색최적화 이슈
    • 문제: 초기 설계에서 검색최적화를 고려하지 못하고, 다량의 트래픽만 고려하여 CSR 방식을 선택하였고, 결과적으로 페이지별 메타, 페이스북 공유하기 등에서 개별 메타 정보 설정이 불가능하게 되었다.
    • 해결: 서버에서 게이트웨이 서비스를 제공해주어, 해당 서비스로 페이지별 메타정보를 전송, 공유 시 개별 페이지 정보를 노출할 수 있게 하였다.

성과

  • 웹뷰에 대한 파악과 문서정리를 통해 추후 인앱에서만 제공되는 프로모션 등의 개발 효율성을 높임
  • CSR 사용의 문제점 및 장점 파악을 통해 타 프로젝트에서 SSR과 CSR선택을 적절하게 고려함
  • 기존 진행되었던 18, 19년도 서비스에 대한 코드 및 기록이 없는 상황에서 리소스 확보 및 재개발을 통해 히스토리 유지에 기여



2. ifkakao 통합

프로젝트 개요

2018~2024년 동안의 ifkakao 페이지의 도메인을 통합하고, 깃을 통합하여 관리하기 위한 목적으로 진행된 프로젝트

프로젝트 정보

  • ifkakao

기술 스택

  • UI: html, scss
  • FRONT: Nuxt3

성과

  • jest를 활용한 프론트 함수별 단위테스트 진행
    • 여러 테스트 케이스를 통해 에러 발생을 사전에 방지
    • TDD 에 대한 경험
  • 2018~2021(nuxt2) 2022(모노코드), 2024(모노코드)를 nuxt3 통합 및 마이그레이션
    • 프론트엔트 프레임워크 팀 내 첫 마이그레이션 진행
    • 카카오에서 지원하는 노코드 플랫폼인 모노코드의 종료에 따라 이를 이용해 개발된 22, 24년도 ifkakao 페이지 마이그레이션
      • api 를 사용하지 않고 데이터 전체를 프론트 내에서 하드코딩
      • 히스토리나 남아있는 코드가 없었기 때문에 서비스되는 페이지를 기반으로 기능 테스트, 리스트업 및 그에 따라 자체 구현
  • 여러 하위 도메인으로 서빙되고 있던 페이지를 하나의 도메인 하위에서 년도별로 관리할 수 있도록 구조화
  • nuxt3 composable을 적절히 적용하여 코어 기능들을 공통으로 관리 및 사용할 수 있도록 처리
